# Reverse Proxy

Requests redirection module.

## Configuration

### Requirements

You need to install the following tools in your machine:

- Docker
- Docker Compose

### Environment variables

Please refer to the application (app folder) README file to set the environment variables correctly.

## Run

### DevOps

To start the application You just need to run the command below inside this folder:

```sh
docker compose up -d
```

To stop the application You just need to run the command below inside this folder:

```sh
docker compose down
```
